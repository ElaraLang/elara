data RenameError Source #

Constructors

UnknownModule ModuleName

A requested module was not found

QualifiedInWrongModule ModuleName ModuleName

A qualified name was used in a declaration but the qualifier doesn't match the current module's name For example, module A; B.x = 1 would trigger this error, because the qualified name B.x is in the wrong module

NonExistentModuleDeclaration ModuleName (Located Name)

A name was referenced with an explicit module qualifier or in an explicit import/hiding list, but that name doesn't exist in (or isn't exported by) the named module. For example, import Foo (nonExistent) or a use of Foo.nonExistent where Foo has no such export

UnknownTypeVariable LowerAlphaName

A type variable was referenced that isn't in scope. For example, type Foo = a would trigger this, because a is not bound anywhere

(ToName name, Show name) => UnknownName

A name was used that isn't in scope, either because it doesn't exist or because it wasn't imported. Carries the unknown name, the module being renamed (for import suggestions), and the full known-names map (for typo hints)

AmbiguousVarName (Located Name) (NonEmpty (VarRef VarName))

A variable name is imported by more than one unqualified import and the use site is ambiguous. For example, importing both Data.Map (lookup) and Data.List (lookup) and then using lookup unqualified

RecursiveTypeAlias (Located (Qualified TypeName)) (Located (Qualified TypeName))
