embedDir :: FilePath -> Q Exp Source #

Embed every file under a directory (relative to the package root) as [(FilePath, ByteString)], with paths relative to that directory. For example $(embedDir "./") might create something like [("a.txt", "hello"), ("b.txt", "aaa")].

Todo: This might not pick up new files without a clean build! Should probably fix this

embedJavaClasses :: FilePath -> Q Exp Source #

Compile the Java sources under a directory with javac and embed the resulting class files as [(FilePath, ByteString)], with paths relative to the classpath root. Needs javac at build time.

readDirRecursive :: FilePath -> IO [(FilePath, ByteString)] Source #

Returns file under a directory, as paths relative to it and their contents, in a stable (but arbitrary) order
